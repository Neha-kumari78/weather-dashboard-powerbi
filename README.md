# Weather Dashboard (Power BI)

A weather and air quality dashboard built in Power BI using data from WeatherAPI.

## What it shows
- Current weather: temperature, humidity, wind speed, visibility, pressure, UV index and precipitation
- 7-day temperature forecast
- Chance of rain for each day
- Air quality: PM2.5, PM10, SO2, O3, NO2 and CO
- Sunrise and sunset times
- City selector (Amritsar, Lucknow, Ludhiana)

## Tools used
- Power BI Desktop
- Power Query (data cleaning)
- DAX (measures and formatting)
- WeatherAPI (data source)

## What I did
- Pulled weather and air quality data from WeatherAPI
- Cleaned the data in Power Query (removed unused columns and duplicates, replaced values)
- Created DAX measures for humidity, wind speed, visibility, pressure and more
- Added units and formatting, and designed a dark-themed dashboard
